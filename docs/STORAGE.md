# 作品、回收站与存储管理

## 用户操作

在“我的作品”中，可搜索全部作品、切换任务状态、按页浏览（每页 20 项），并单项或批量移入回收站。

- **删除**：只把已结算作品移入回收站，默认保留 30 天，可在期限内恢复。移动时固定该项截止时间；以后修改后台天数不追溯改变它。
- **恢复**：回到“我的作品”，不重新调用模型、不再次扣积分。若设置了作品自动到期，恢复后重新计算保留时间。
- **永久清除**：仅对回收站项目提供，需要单独确认。不可恢复，保留任务结算与积分流水；文件如仍被其他作品、回收站作品或任务引用，则暂时保留，直到引用解除。
- queued、running 与 uncertain 任务不能删除；需等待结算或管理员核对。用户删除不等于取消上游调用，也不会退还已成功消费积分。
- 回收站到期后不可恢复。每小时清理会清除过期项目；如应用停机，待恢复运行后的定时清理处理。

永久清除的任务保留审计与账务用记录，但不再在用户作品或回收站列表中展示。图片文件清理不删除账户余额、兑换记录、订单或消费账本。历史备份可能仍包含原文件，需要按管理员的独立备份保留策略处理，在线清理不会直接修改备份。

## 空间如何计算

“我的作品”顶部显示实际图片用量、任务预留、剩余空间、每日上传次数与保留规则。

- 上传原图（重新编码后的保存文件）、蒙版、生成结果、回收站与等待物理删除的文件均计入空间。
- 原图会去除元数据、重新编码并按原规则规整尺寸；统计保存后的字节数。上传文件本身和保存后文件都受到单张上传上限约束。
- 相同图片重复上传仍为独立文件，分别计数，目前不做跨用户或跨资产去重。
- 移入回收站不释放空间；永久清除后实际文件被移除才释放。仍被引用的文件继续计入原账户，不会转移到别人名下。
- 备份、SQLite、测试邮件不属于图片额度，不计入本页用量；管理员仍应监测服务器总磁盘。

每日上传额度按北京时间零点重置，参考图与蒙版都计数；删除不返还当日次数。生成结果不占上传次数。

提交模型任务前，每张按 **20 MiB** 预留空间，并与积分冻结在同一个数据库事务中完成；空间不足时拒绝任务，不扣积分，也不调用模型。这是保守空间预留，不是额外积分收费。产物保存后释放相应预留，最终结算时清除剩余预留。结果不明任务继续保留预留，待核对；任务在提交时已获预留后，即使管理员降低额度，也会尽量保存已执行任务的结果。

## 管理员配置

入口：`/?page=admin&adminTab=storage`。

| 设置 | 默认值 | 范围 |
| --- | ---: | --- |
| 每用户图片存储 | 1024 MiB（1 GiB） | 40–1,048,576 MiB |
| 单张上传 | 20 MiB | 1–20 MiB |
| 每用户每日上传次数 | 100 | 1–10,000 |
| 回收站保留时间 | 30 天 | 1–365 天 |
| 作品自动保留时间 | 0（不自动到期） | 0–3650 天 |
| 未使用素材保留时间 | 7 天 | 1–365 天 |

限额是全站统一的每用户额度，当前不区分套餐或单用户覆盖。设置修改有版本校验与管理员审计。降低限额不会立即删掉现有内容，但可能阻止用户继续上传和生成。启用作品自动到期会影响原有旧作品：按最后完成/恢复时间到期后先移入回收站，不会直接永久删除。

管理员可以查看全站图片/预留总量及分页用户用量，手动确认执行到期清理。自动清理每小时执行一次；该模块只处理图片和作品，不清理数据库、备份、邮件或项目目录。

## 引用保护与文件清理

物理文件只有满足以下条件才进入清理：

1. 不属于任何未永久清除的作品输出。
2. 不被未永久清除的任务作为参考图或蒙版引用。
3. 不是进行中/待核对任务尚未关联完成的输出。
4. 属于已永久清除作品的可回收输出，或者未被使用且超过保留期限的素材。

有进行中或待核对任务时，同账户的未关联旧素材也会保留，避免任务执行中误删。恢复回收站不突破引用保护；永久清除后新任务不能再使用已经清理的资产 ID。

删除文件前先写入不可访问标记，阻止新的引用；文件操作校验目录和文件名，只 unlink 数据库定位到的普通图片文件，不接受目录穿越，不跟随符号链接，不执行递归删除。删除失败保留待处理状态和用量，下次清理重试；不会向用户误报已释放对应空间。

首次迁移自动补齐作品删除状态、文件大小和预留字段，并在启动时从原文件回填实际大小。历史任务与积分保持不变；尚未回填时按每张 20 MiB 保守估算。现有素材缺失会阻止启动并提示修复，以免把错误统计作为额度依据。

## 备份与清理互斥

`npm run backup` 与图片清理共用 `data/media-maintenance.lock`，确保备份快照引用的文件在复制期间不会被清除。图片保存为不可变文件，先写文件再登记数据库，故新上传不会破坏已有备份快照。

备份保留数据库中的已清除审计记录，但只复制仍可访问的媒体；已物理清理的 tombstone 不要求存在对应文件。校验支持旧版未引入清理字段的备份。恢复演练包含积分余额、作品 tombstone 和媒体一致性。

锁文件会在正常操作结束时移除；异常进程退出后，工具可识别已退出的持有进程。若无法确认锁持有者，不会强行开始清理，请先核对实际备份进程状态。

## 本轮验证边界

自动化覆盖单项/批量操作、跨账户隔离、活动任务保护、过期/恢复、共享素材保护、上传/任务预留限额、删除后账本不变、文件路径约束及清理与备份互斥。没有为验证新增真实生图调用，也没有主动删除现有实际用户作品。

浏览器布局、手机触控和真实服务器磁盘/权限仍需实际验收；图片额度不能替代服务器磁盘告警。S3/OSS/R2、缩略图、单用户套餐额度和备份自动过期不在本轮实现范围内。
